# Contactos Comerciales Construcción

App web instalable (PWA) para Android: fotografía una tarjeta de visita, lee los datos en el propio móvil y permite encontrar el contacto por nombre, apellido o empresa, también por voz.

- La lectura del texto se hace en el teléfono con [Tesseract.js](https://github.com/naptha/tesseract.js) (Apache 2.0) y el modelo de idioma español. Ninguna foto ni ningún dato sale del móvil.
- Los contactos se guardan en el almacenamiento del navegador del teléfono. Desde el menú ⋮ se puede guardar y restaurar una copia de seguridad.
- Funciona sin conexión una vez abierta por primera vez.

Este repositorio contiene solo el código de la app; no contiene ningún contacto.
